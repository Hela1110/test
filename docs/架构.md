### 1.2 架构特点

#### 1.2.1 分层设计
- **表现层**: Qt GUI界面,负责用户交互和数据展示
- **网络层**: Socket长连接,负责客户端与服务器通信
- **业务层**: 服务端业务逻辑处理,封装核心功能
- **持久层**: ORM框架,负责数据库访问和对象映射
- **数据层**: MySQL数据库,负责数据持久化存储

#### 1.2.2 优势
- **高内聚低耦合**: 各层职责清晰,易于维护和扩展
- **跨语言协作**: C++客户端 + Java服务器,发挥各自优势
- **高性能**: Netty异步IO + 数据库索引优化
- **事务保证**: Spring事务管理确保数据一致性
- **易扩展**: 模块化设计,方便添加新功能

#### 2.2.4 Netty网络框架
**服务器启动代码**:
```java
@Component
public class SocketServer {
    
    private final int port;
    private EventLoopGroup bossGroup;
    private EventLoopGroup workerGroup;
    
    public SocketServer(@Value("${socket.port:9090}") int port) {
        this.port = port;
    }
    
    public void start() {
        bossGroup = new NioEventLoopGroup(1);
        workerGroup = new NioEventLoopGroup();
        
        try {
            ServerBootstrap bootstrap = new ServerBootstrap();
            bootstrap.group(bossGroup, workerGroup)
                .channel(NioServerSocketChannel.class)
                .option(ChannelOption.SO_BACKLOG, 128)
                .childOption(ChannelOption.SO_KEEPALIVE, true)
                .childHandler(new ChannelInitializer<SocketChannel>() {
                    @Override
                    protected void initChannel(SocketChannel ch) {
                        ChannelPipeline pipeline = ch.pipeline();
                        pipeline.addLast(new LineBasedFrameDecoder(8192));
                        pipeline.addLast(new StringDecoder(CharsetUtil.UTF_8));
                        pipeline.addLast(new StringEncoder(CharsetUtil.UTF_8));
                        pipeline.addLast(messageHandler);  // 业务处理器
                    }
                });
            
            ChannelFuture future = bootstrap.bind(port).sync();
            log.info("Socket server started on port {}", port);
            future.channel().closeFuture().sync();
        } catch (Exception e) {
            log.error("Socket server failed", e);
        } finally {
            shutdown();
        }
    }
    
    public void shutdown() {
        if (bossGroup != null) bossGroup.shutdownGracefully();
        if (workerGroup != null) workerGroup.shutdownGracefully();
    }
}
```

### 3.1 用户认证模块

#### 3.1.1 注册流程
```
用户输入 → 客户端验证 → 发送register消息 → 服务端校验 
→ 密码加密 → 插入数据库 → 返回结果
```

**客户端验证**:
- 用户名长度: 3-20字符
- 密码强度: 至少6字符
- 手机号格式: 11位数字
- 邮箱格式: RFC 5322标准

**服务端处理**:
```java
public Map<String, Object> register(String username, String password, 
                                     String phone, String email) {
    // 1. 检查用户名是否存在
    if (clientRepository.existsByUsername(username)) {
        return Map.of("success", false, "message", "用户名已存在");
    }
    
    // 2. 密码加密(BCrypt)
    String hashedPassword = passwordEncoder.encode(password);
    
    // 3. 创建用户实体
    Client client = new Client();
    client.setUsername(username);
    client.setPassword(hashedPassword);
    client.setPhone(phone);
    client.setEmail(email);
    client.setRole("USER");
    client.setEnabled(true);
    
    // 4. 保存到数据库
    clientRepository.save(client);
    
    return Map.of("success", true, "message", "注册成功");
}
```

#### 3.1.2 登录流程
```
用户输入 → 发送login消息 → 服务端查询用户 → 密码校验 
→ 检查enabled状态 → 返回用户信息
```

**服务端处理**:
```java
public Map<String, Object> login(String username, String password) {
    // 1. 查询用户
    Optional<Client> clientOpt = clientRepository.findByUsername(username);
    if (!clientOpt.isPresent()) {
        return Map.of("success", false, "code", 1001, 
                     "message", "用户名或密码错误");
    }
    
    Client client = clientOpt.get();
    
    // 2. 检查是否被禁用
    if (!client.getEnabled()) {
        return Map.of("success", false, "code", 1003, 
                     "message", "该账号已被禁用,请联系管理员");
    }
    
    // 3. 密码校验
    if (!passwordEncoder.matches(password, client.getPassword())) {
        return Map.of("success", false, "code", 1001, 
                     "message", "用户名或密码错误");
    }
    
    // 4. 返回用户信息
    return Map.of(
        "success", true,
        "clientId", client.getClientId(),
        "username", client.getUsername(),
        "role", client.getRole()
    );
}
```

### 3.2 商品推荐模块

#### 3.2.1 智能推荐算法
**推荐策略**:
1. 销量最高商品(标记isHot=true) - 引导用户关注热门
2. 最新商品(product_id最大) - 展示新品
3. 2个打折商品 - 促进销售
4. 兜底策略: 不足4个时用上架商品补充

**实现代码**:
```java
private void handleGetRecommendations(ChannelHandlerContext ctx) {
    List<Map<String,Object>> list = new ArrayList<>();
    
    // 1. 销量最高(isHot=true)
    Product topSales = productRepository.findTopByOnSaleTrueOrderBySalesDesc();
    if (topSales != null) {
        Map<String,Object> item = productToMap(topSales);
        item.put("isHot", true);
        item.put("isNew", false);
        list.add(item);
    }
    
    // 2. 最新商品(isNew=true)
    Product newest = productRepository.findTopByOrderByProductIdDesc();
    if (newest != null && !isDuplicate(list, newest)) {
        Map<String,Object> item = productToMap(newest);
        item.put("isNew", true);
        item.put("isHot", false);
        list.add(item);
    }
    
    // 3. 2个打折商品
    List<Product> discounts = productRepository.findTopDiscountProducts(
        PageRequest.of(0, 10)
    );
    int count = 0;
    for (Product p : discounts) {
        if (count >= 2) break;
        if (!isDuplicate(list, p)) {
            list.add(productToMap(p));
            count++;
        }
    }
    
    // 4. 兜底: 补充到4个
    if (list.size() < 4) {
        List<Product> fallback = productRepository.findByOnSaleTrue();
        for (Product p : fallback) {
            if (list.size() >= 4) break;
            if (!isDuplicate(list, p)) {
                list.add(productToMap(p));
            }
        }
    }
    
    sendResponse(ctx, Map.of("type", "recommendations", "products", list));
}
```

### 3.3 订单管理模块

#### 3.3.1 下单流程(事务保证)
```
购物车结算 → 校验库存 → 创建订单头 → 创建订单明细 
→ 扣减库存 → 更新销量 → 记录库存变动 → 清空购物车
```

**事务代码**:
```java
@Service
@Transactional  // Spring声明式事务
public class OrderService {
    
    public OrderHeader createOrder(Long clientId, List<OrderItemDTO> items) {
        // 1. 校验库存(失败抛异常,事务自动回滚)
        for (OrderItemDTO item : items) {
            Product product = productRepository.findById(item.getProductId())
                .orElseThrow(() -> new RuntimeException("商品不存在"));
            
            if (product.getStock() < item.getQuantity()) {
                throw new RuntimeException("库存不足: " + product.getName());
            }
        }
        
        // 2. 创建订单头
        OrderHeader order = new OrderHeader();
        order.setClient(clientRepository.findById(clientId).get());
        order.setOrderNo(generateOrderNo());  // 生成唯一订单号
        order.setStatus("PENDING");
        order.setOrderTime(LocalDateTime.now());
        order = orderHeaderRepository.save(order);
        
        // 3. 创建订单明细并扣减库存
        BigDecimal totalAmount = BigDecimal.ZERO;
        for (OrderItemDTO itemDTO : items) {
            Product product = productRepository.findById(itemDTO.getProductId()).get();
            
            // 创建订单明细
            OrderItem item = new OrderItem();
            item.setOrderHeader(order);
            item.setProduct(product);
            item.setQuantity(itemDTO.getQuantity());
            item.setPrice(product.getPrice());  // 记录下单时价格
            item.setSize(itemDTO.getSize());
            orderItemRepository.save(item);
            
            // 扣减库存
            product.setStock(product.getStock() - itemDTO.getQuantity());
            product.setSales(product.getSales() + itemDTO.getQuantity());
            productRepository.save(product);
            
            // 记录库存变动
            StockMovement movement = new StockMovement();
            movement.setProduct(product);
            movement.setQuantity(-itemDTO.getQuantity());
            movement.setType("SALE");
            movement.setReason("订单销售: " + order.getOrderNo());
            movement.setMovementTime(LocalDateTime.now());
            stockMovementRepository.save(movement);
            
            // 累加金额
            totalAmount = totalAmount.add(
                product.getPrice().multiply(BigDecimal.valueOf(itemDTO.getQuantity()))
            );
        }
        
        // 4. 更新订单总价
        order.setTotalAmount(totalAmount);
        return orderHeaderRepository.save(order);
    }
    
    private String generateOrderNo() {
        return "ORD" + LocalDateTime.now().format(
            DateTimeFormatter.ofPattern("yyyyMMddHHmmss")
        ) + new Random().nextInt(1000);
    }
}
```

#### 3.4.1 饼状图商品销售统计
**查询逻辑**:
```java
private void handleGetStats(ChannelHandlerContext ctx, JsonNode request) {
    String startDate = request.get("startDate").asText();
    String endDate = request.get("endDate").asText();
    
    LocalDateTime start = LocalDate.parse(startDate).atStartOfDay();
    LocalDateTime end = LocalDate.parse(endDate).atTime(23, 59, 59);
    
    // 统计查询
    List<Object[]> rawData = orderItemRepository.sumSalesByProduct(start, end);
    
    List<Map<String,Object>> productStats = new ArrayList<>();
    for (Object[] row : rawData) {
        Long productId = (Long) row[0];
        String name = (String) row[1];
        Long quantity = (Long) row[2];
        BigDecimal amount = (BigDecimal) row[3];
        
        Map<String,Object> productInfo = new HashMap<>();
        productInfo.put("productId", productId);
        productInfo.put("name", name);
        productInfo.put("quantity", quantity);
        productInfo.put("amount", amount);
        
        // 【新增】查询商品详细信息
        try {
            Optional<Product> productOpt = productRepository.findById(productId);
            if (productOpt.isPresent()) {
                Product p = productOpt.get();
                productInfo.put("price", p.getPrice());
                productInfo.put("discountPrice", p.getDiscountPrice());
                productInfo.put("stock", p.getStock());
                productInfo.put("imageUrl", p.getImageUrl());
                productInfo.put("sales", p.getSales());
            }
        } catch (Exception ignore) {}
        
        productStats.add(productInfo);
    }
    
    sendResponse(ctx, Map.of(
        "type", "stats_response",
        "productStats", productStats
    ));
}
```
