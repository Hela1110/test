## 1. 项目概述

### 1.1 项目背景
随着电子商务的快速发展,传统购物模式逐渐向线上转移。本项目旨在开发一个功能完善的桌面端购物系统,实现商品浏览、购物车管理、订单处理、数据统计等完整的电商业务流程。

### 1.2 项目目标
- ✅ 设计并实现C/S架构的购物系统
- ✅ 提供友好的图形用户界面
- ✅ 实现完整的用户认证和权限管理
- ✅ 支持商品管理、订单处理等核心业务
- ✅ 提供管理员端的数据统计分析功能
- ✅ 实现客服聊天系统

### 1.3 项目特色
- **跨语言开发**: 前端C++/Qt + 后端Java/Spring Boot
- **双端协同**: 客户端-服务器实时通信
- **现代化UI**: 响应式设计,支持emoji图标美化
- **数据可视化**: 饼状图、柱状图展示销售数据
- **热卖推荐**: 智能推荐系统(销量最高+新品+打折商品)

#### 4.2.3 智能推荐算法
```java
// 获取推荐商品: 销量最高 + 新品 + 2个打折商品
private void handleGetRecommendations(ChannelHandlerContext ctx) {
    List<Map<String,Object>> list = new ArrayList<>();
    
    // 1. 销量最高的商品(标记isHot=true)
    Product topSales = productRepository.findTopByOnSaleTrueOrderBySalesDesc();
    if (topSales != null) {
        Map<String,Object> item = toMap(topSales);
        item.put("isHot", true);
        item.put("isNew", false);
        list.add(item);
    }
    
    // 2. 最新商品(product_id最大)
    Product newest = productRepository.findTopByOrderByProductIdDesc();
    if (newest != null && !isDuplicate(list, newest)) {
        Map<String,Object> item = toMap(newest);
        item.put("isNew", true);
        item.put("isHot", false);
        list.add(item);
    }
    
    // 3. 2个打折商品
    List<Product> discounts = productRepository.findTopDiscountProducts(
        PageRequest.of(0, 10)
    );
    int count = 0;
    for (Product p : discounts) {
        if (count >= 2) break;
        if (!isDuplicate(list, p)) {
            list.add(toMap(p));
            count++;
        }
    }
    
    // 4. 补充到4个
    if (list.size() < 4) {
        List<Product> fallback = productRepository.findByOnSaleTrue();
        for (Product p : fallback) {
            if (list.size() >= 4) break;
            if (!isDuplicate(list, p)) {
                list.add(toMap(p));
            }
        }
    }
    
    Map<String, Object> response = Map.of(
        "type", "recommendations",
        "products", list
    );
    sendResponse(ctx, response);
}
```

#### 4.2.4 订单事务处理
```java
@Service
@Transactional
public class OrderService {
    
    // 创建订单(事务保证原子性)
    public OrderHeader createOrder(Long clientId, List<OrderItemDTO> items) {
        // 1. 校验库存
        for (OrderItemDTO item : items) {
            Product product = productRepository.findById(item.getProductId())
                .orElseThrow(() -> new RuntimeException("商品不存在"));
            
            if (product.getStock() < item.getQuantity()) {
                throw new RuntimeException("库存不足: " + product.getName());
            }
        }
        
        // 2. 创建订单头
        OrderHeader order = new OrderHeader();
        order.setClient(clientRepository.findById(clientId).get());
        order.setOrderNo(generateOrderNo());
        order.setStatus("PENDING");
        order.setOrderTime(LocalDateTime.now());
        order = orderHeaderRepository.save(order);
        
        // 3. 创建订单明细并扣减库存
        BigDecimal totalAmount = BigDecimal.ZERO;
        for (OrderItemDTO itemDTO : items) {
            Product product = productRepository.findById(itemDTO.getProductId()).get();
            
            OrderItem item = new OrderItem();
            item.setOrderHeader(order);
            item.setProduct(product);
            item.setQuantity(itemDTO.getQuantity());
            item.setPrice(product.getPrice());
            orderItemRepository.save(item);
            
            // 扣减库存
            product.setStock(product.getStock() - itemDTO.getQuantity());
            product.setSales(product.getSales() + itemDTO.getQuantity());
            productRepository.save(product);
            
            // 记录库存变动
            StockMovement movement = new StockMovement();
            movement.setProduct(product);
            movement.setQuantity(-itemDTO.getQuantity());
            movement.setType("SALE");
            movement.setReason("订单销售: " + order.getOrderNo());
            stockMovementRepository.save(movement);
            
            totalAmount = totalAmount.add(
                product.getPrice().multiply(BigDecimal.valueOf(itemDTO.getQuantity()))
            );
        }
        
        // 4. 更新订单总价
        order.setTotalAmount(totalAmount);
        return orderHeaderRepository.save(order);
    }
}

@Repository
public interface OrderItemRepository extends JpaRepository<OrderItem, Long> {
    
    // 按商品统计销量和销售额
    @Query("SELECT oi.product.productId, oi.product.name, " +
           "SUM(oi.quantity), SUM(oi.price * oi.quantity) " +
           "FROM OrderItem oi " +
           "JOIN oi.orderHeader oh " +
           "WHERE oh.orderTime BETWEEN :start AND :end " +
           "GROUP BY oi.product.productId, oi.product.name " +
           "ORDER BY SUM(oi.quantity) DESC")
    List<Object[]> sumSalesByProduct(
        @Param("start") LocalDateTime start,
        @Param("end") LocalDateTime end
    );
    
    // 按月份统计销售额
    @Query("SELECT YEAR(oh.orderTime), MONTH(oh.orderTime), " +
           "SUM(oh.totalAmount) " +
           "FROM OrderHeader oh " +
           "WHERE oh.orderTime BETWEEN :start AND :end " +
           "GROUP BY YEAR(oh.orderTime), MONTH(oh.orderTime) " +
           "ORDER BY YEAR(oh.orderTime), MONTH(oh.orderTime)")
    List<Object[]> sumByMonth(
        @Param("start") LocalDateTime start,
        @Param("end") LocalDateTime end
    );
}
```

### 4.3 数据库设计

#### 4.3.1 核心表结构

**用户表 (clients)**:
```sql
CREATE TABLE clients (
    client_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(100) NOT NULL,  -- BCrypt加密
    phone VARCHAR(20),
    email VARCHAR(100),
    role VARCHAR(20) DEFAULT 'USER',  -- USER/ADMIN
    enabled BOOLEAN DEFAULT TRUE,     -- 账号启用状态
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**商品表 (products)**:
```sql
CREATE TABLE products (
    product_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    discount_price DECIMAL(10,2),     -- 折扣价
    description TEXT,
    image_url VARCHAR(500),           -- 图片URL
    stock INT DEFAULT 0,              -- 库存
    sales INT DEFAULT 0,              -- 累计销量
    on_sale BOOLEAN DEFAULT TRUE,     -- 是否上架
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_sales (sales DESC),     -- 销量索引
    INDEX idx_on_sale (on_sale)       -- 上架状态索引
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**订单头表 (order_headers)**:
```sql
CREATE TABLE order_headers (
    order_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    order_no VARCHAR(50) UNIQUE NOT NULL,
    client_id BIGINT NOT NULL,
    total_amount DECIMAL(10,2) NOT NULL,
    status VARCHAR(20) DEFAULT 'PENDING',  -- PENDING/PAID/SHIPPED/COMPLETED/CANCELLED
    order_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (client_id) REFERENCES clients(client_id),
    INDEX idx_client (client_id),
    INDEX idx_status (status),
    INDEX idx_time (order_time DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**订单明细表 (order_items)**:
```sql
CREATE TABLE order_items (
    item_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    order_id BIGINT NOT NULL,
    product_id BIGINT NOT NULL,
    quantity INT NOT NULL,
    price DECIMAL(10,2) NOT NULL,  -- 下单时价格(历史价格)
    size INT,                      -- 商品尺码
    FOREIGN KEY (order_id) REFERENCES order_headers(order_id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES products(product_id),
    INDEX idx_order (order_id),
    INDEX idx_product (product_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 4.3.2 索引优化策略
- **销量索引**: `idx_sales` - 加速"按销量排序"查询
- **上架状态索引**: `idx_on_sale` - 快速筛选上架商品
- **订单时间索引**: `idx_time` - 优化订单列表分页查询
- **外键索引**: 自动为外键创建索引,提升JOIN性能

## 5. 核心亮点

### 5.1 技术亮点

#### 5.1.1 跨语言架构设计
- **前后端分离**: C++客户端 + Java服务器,充分发挥各语言优势
- **统一协议**: 基于JSON的跨平台消息格式
- **类型安全**: 前端静态类型(C++) + 后端强类型(Java)

#### 5.1.2 高性能网络通信
- **Netty异步IO**: 基于事件驱动的非阻塞网络框架
- **长连接保持**: TCP连接复用,减少握手开销
- **心跳检测**: 自动断线重连,提高可靠性
- **消息队列**: 缓冲消息,避免网络阻塞

#### 5.1.3 智能推荐系统
- **多维度推荐**: 销量、新品、折扣综合推荐
- **去重算法**: 避免同一商品重复推荐
- **兜底策略**: 推荐不足时自动补充商品
- **实时更新**: 商品销量实时统计,推荐即时生效

#### 5.1.4 事务一致性保证
- **Spring事务管理**: `@Transactional`注解声明式事务
- **库存扣减**: 订单创建与库存扣减原子操作
- **并发控制**: 数据库行级锁防止超卖
- **异常回滚**: 任何步骤失败自动回滚全部操作

#### 5.1.5 ORM持久化
- **JPA规范**: 标准化的对象关系映射
- **方法命名查询**: 无需写SQL,自动生成查询
- **懒加载**: 按需加载关联对象,提高性能
- **二级缓存**: Hibernate二级缓存减少数据库访问

### 7.2 遇到的问题与解决

#### 7.2.1 中文编码问题
**问题**: Windows环境下中文字符在源码中显示为乱码  
**原因**: 文件编码不一致(UTF-8 vs GBK)  
**解决**: 统一使用UTF-8编码,数据库使用utf8mb4字符集

#### 7.2.2 库存并发问题
**问题**: 多用户同时下单可能导致库存超卖  
**原因**: 缺少并发控制机制  
**解决**: 使用数据库事务和行级锁,确保库存扣减的原子性

#### 7.2.3 网络断线问题
**问题**: 客户端断线后无法自动恢复  
**原因**: 未实现重连机制  
**解决**: 添加心跳检测和自动重连逻辑

#### 7.2.4 图表数据对齐
**问题**: 饼状图点击显示的商品信息不完整  
**原因**: 统计查询只返回了部分字段  
**解决**: 在统计查询后补充查询商品完整信息
